# host-telemetry-mcp

Model Context Protocol (MCP) server for local system inspection.

## What it does

Exposes tools for AI agents to query host CPU/RAM metrics, NVIDIA GPU telemetry, and running systemd user services.

## Setup

```bash
npm install
npm run build
```
